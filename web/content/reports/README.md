# 주간 리포트 해설 (R-35)

`/reports/<주차>/<지역>/` 페이지는 마감 데이터로 자동으로 만들어진다. 여기에 작성자 해설을 넣으면 페이지 맨 위에 "운영자 해설"로 붙고, 그때부터 검색에 색인된다(해설 없는 자동 페이지는 noindex).

- 파일 이름: `<주차>-<지역>.<언어>.md` — 예: `1-kr.ko.md`, `1-kr.en.md`, `1-tw.zh-tw.md`
- 내용: 문단을 빈 줄로 나눈 일반 글. 마크다운 서식은 쓰지 않는다(링크·굵게 없이 문장만)
- 길이: 3~6문단. 숫자는 페이지가 보여 주니, 해설은 "왜", "누가 눈에 띄었나", "다음 주 볼 것"을 쓴다
- 사실만 쓴다. 개인 비난·접속 시간 언급 금지
